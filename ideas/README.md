# 漫剧创意库

这里保存尚未进入正式立项与大纲阶段的创意种子。Idea 文件只固定核心机制、情绪承诺、长线可能性与主要风险，不代表已经决定制作。

| 编号 | 暂定名称 | 类型 | 当前状态 | 核心看点 |
|---|---|---|---|---|
| 001 | 冒牌强者智斗引擎 | 爽剧机制 / 可跨题材 | 待选世界容器 | 弱者靠智斗制造无限强者幻觉，真实成长永远落后于外界传说 |
| 002 | 妖结与解灵师（暂名） | 妖怪心理悬疑 / 精品单元剧 | 核心机制已确认 | 妖因与独立人格冲突形成妖结和怪象，解灵师溯因、识结并帮助妖怪作出选择 |

## 使用约定

- 确认立项后，再建立独立项目目录并补齐 `project.md`、`outline.md`、`characters.md` 和 `catalog.md`。
- Idea 阶段允许保留多个题材方向，不提前扩写80集目录。
- 后续讨论产生的新机制、淘汰理由与验证结果，优先回写对应 Idea 文件。
