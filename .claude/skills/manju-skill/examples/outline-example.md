# 【示例大纲】末日重生:我囤积了百亿物资

## 1. 项目基础信息 (Project Profile)

- **作品名称**：《末日重生:我囤积了百亿物资》
- **一句话卖点**：重生回到末日前一小时,这一世我只做恶人,让那些道德婊全部跪下求我
- **核心爽感**：绝对支配 + 复仇爽感 + 女神坠落
- **对标作品**：《无双》(短剧) + 《末日曙光》(动态漫)
- **总集数**：70集(每集120秒)

---

## 2. 核心设定 (Core Concept)

### 金手指系统 (Cheat System)
```yaml
名称: 末日囤货系统
核心功能: 重生+无限空间+百倍返还(存入1吨物资,取出时变100吨)
视觉表现:
  - 初级(1-10集): 眼前浮现半透明的蓝色仓库界面,显示物资数量
  - 中级(11-30集): 凭空召唤物资,从虚空中落下成堆的箱子
  - 高级(31-60集): 召唤大型建筑/装甲车/武器库
  - 终极(61-70集): 改写区域规则,让荒地变绿洲
限制条件: 
  - 只能存储非生命体
  - 百倍返还需要24小时冷却
  - 空间容量随主角等级提升
```

### 动态等级体系 (Level System)
```yaml
Level 1 (1-10集): 重生幸存者 - 目标:囤货/复仇第一批恶人
Level 2 (11-25集): 安全屋霸主 - 目标:建立小型基地/收服美女
Level 3 (26-45集): 区域领主 - 目标:扫荡周边势力/建立规则
Level 4 (46-60集): 末世之王 - 目标:对抗军方/揭秘末日真相
Level 5 (61-70集): 新世界之神 - 目标:重塑文明/登上神座
```

## 5. 剧本自检

1. ✅ 节奏是否太慢? → 第1集直接开局爽点,无废话
2. ✅ 视觉是否足够? → 每集至少3个可视化特效场景
3. ✅ 主角是否吃瘪太久? → 最多压抑2集立刻反弹
4. ✅ 擦边是否高级? → 全程强调"不得不"的情境,无低俗描写
