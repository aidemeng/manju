# 【示例剧本】第3集:女神献媚

## 1. 本集基础信息 (Episode Info)
- **集数**：第 3 集
- **标题**：女神献媚
- **时长预估**：120秒 (约28个分镜)
- **核心任务**：通过校花苏晴雨从高冷到献媚的落差，展示主角萧凡的绝对支配力，引发观众的爽感和期待
- **情绪基调**：压抑→羞辱→诱惑→期待

## 3. 场景详解与设计意图

### 启(0-15s):为什么这样设计?
- **对比强烈**: 校花从高冷到跪地乞求的落差
- **视觉冲击**: 雨、泥污、撕裂的衣服强化了她的狼狈
- **心理反差**: 观众的预期与现实的碰撞 → 爽感产生

### 程(15-60s):张力的积累
- **压抑值拉满**: 丧尸逼近、苏晴雨求救、萧凡冷漠旁观
- **心理游戏**: 萧凡享受看高冷女神的绝望,这才是真正的虐
- **时间压力**: 丧尸不断靠近制造紧张感

### 转(60-100s):爽感释放
- **绝对碾压**: 一击电流秒杀丧尸,展示实力
- **身份反转**: 曾经的校霸现在对萧凡臣服
- **擦边升级**: "洗干净后来我办公室"暗示更多,留下想象空间
- **视觉暧昧**: 浴室、毛巾、赤足,增加张力而不低俗

### 勾(100-120s):钩子设计
- **欲望打断**: 正当CP互动升温时,突然警报打断
- **新危机**: 狼王登场,制造下集期待
- **双钩设计**: 既期待CP发展,又想看萧凡如何应对危机
