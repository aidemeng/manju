# AI漫剧创作 Skill (Manju-Skill)

## 1. 爆款密码：视觉多巴胺与情绪闭环
> **对标参考**：动态漫（如《逆天邪神》、《灵剑尊》）、爆款短剧（如《无双》、《哎呀皇后娘娘来打工》）、男频爽文广告素材。

### 用户心理洞察 (Short Drama Psychology)
1.  **视觉饥渴**：不论是美女、特效还是豪车，用户首先是**“看”**剧。画面必须极度精致或极度刺激。
2.  **两分钟耐受度**：用户的耐心只有120秒。必须在这段时间内完成“压抑-爆发”的完整闭环。
3.  **代入感（爽文逻辑）**：主角必须替用户完成现实中做不到的事（暴富、拥有超能力、被美女环绕）。
4.  **窥私欲（擦边逻辑）**：既想看高高在上的女神，又想看她私下里狼狈或依恋主角的一面。

## 3. 核心能力 (Core Capabilities)
1.  **Visual Translation (画面转化)**：将抽象的“爽”转化为AI可画的“图”。例如将“气势逼人”转化为“脚下地面龟裂、身边气浪吹飞路人”。
2.  **Pacing Control (节奏控制)**：严格执行“3秒-45秒-90秒-120秒”的时间轴结构。
3.  **Hook Engineering (钩子工程)**：在每一集的结尾植入“不得不点”的视觉悬念。

## 4. 爆款公式库 (Visual Formula Library)

### 公式1：视觉打脸循环 (Face-Slapping Visuals)
*频率：每3集必用*
```text
被轻视(特写反派鄙视眼神) → 隐藏实力(主角冷笑/不屑) → 关键出手(全屏特效炸裂/豪车车队入场) → 一击碾压(反派被气浪震飞/跪地) → 围观震惊(众人O型嘴特写)
```

### 公式2：具象化升级 (Tangible Upgrade)
*频率：每次突破/系统奖励必用*
```text
瓶颈困境 → 系统/奇遇提示(UI界面弹窗) → 实体变化(破屋变别墅/废铁变神剑/宠物兽娘进化) → 主角外貌微调(更帅/发光) → 属性面板展示
```

### 公式3：暧昧张力 (Romantic Tension)
*频率：每5集必用 (含擦边设定)*
```text
突发危机(中毒/寒冷/狭小空间) → 不得不接触(为了生存/治疗) → 特写镜头(汗水/泛红的皮肤/紧抓的手指) → 眼神拉丝 → 外力打断(怪物撞门/配角闯入)
```
*关键点：重点描写“不得不”的客观理由，消除低俗感，增加宿命感。*

### 公式4：Boss登场与吃瘪 (Villain Pattern)
*频率：每个Arc必用*
```text
Boss霸气出场(自带BGM/随从开路) → 想要抢夺主角资源/女人 → 主角展示更高阶的底牌(降维打击) → Boss怀疑人生 → Boss认怂或被秒杀
```

## 5. 节奏密度标准 (120s Standard)

| 时间节点 | 内容要求 (Content) | 视觉要求 (Visual) |
| :--- | :--- | :--- |
| **0-3s** | **黄金开场** | 强冲突画面（争吵/打斗/美女受难）或 强悬念（神秘背影/倒计时）。色调饱和度高。 |
| **30-45s** | **小钩子/冲突** | 抛出一个新问题或者展示一个新道具。画面需有特写。 |
| **90s** | **核心高潮** | 反转发生，爽感释放。全景镜头展示大场面特效或群像反应。 |
| **110-120s** | **终极悬念** | 新危机出现（如：背后出现一只手搭在主角肩上）。画面卡在最紧张的一帧，黑屏出字幕。 |
