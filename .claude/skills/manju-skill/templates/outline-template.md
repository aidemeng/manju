## 4. 关键点检查表 (Checklist)

### 爽点分布 (Satisfaction Points)
- [ ] **第3集**：是否完成了第一次像样的反击/打脸？
- [ ] **第10集**：是否让第一波反派彻底下线（死/破产/疯）？
- [ ] **第25集**：是否建立了至少两人的修罗场关系？
- [ ] **第40集**：主角的财富/物资是否达到了"花不完"的程度？

### 付费钩子设计 (Paywall Design)
- **悬念型**：第3集末，门外传来的敲门声到底是谁？（怪物还是美女？）
- **危机型**：第20集末，女神为了保护主角，挡了一刀。
- **反转型**：第30集末，一直帮助主角的老爷爷，露出了诡异的笑容。

## 5. 剧本自检 (Self-Correction)
*生成完大纲后，请AI自我检查*
1.  **节奏是否太慢？** (是否前5集都在铺垫？如果是，请压缩到1集)
2.  **视觉是否足够？** (是否全是对白？必须增加动作和特效描述)
3.  **主角是否吃瘪太久？** (压抑不能超过3集，必须马上反弹)
4.  **擦边是否高级？** (拒绝低俗，强调"不得不"的情境张力)
